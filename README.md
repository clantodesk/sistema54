# 54 Desk

Brand di ClantoDesk per Sistema 54 (livello 1, Windows e macOS).

Questo repo contiene solo `brand.json` e `icons/`. La build la fa il workflow
«Partner build» di `clanto/clantodesk-client` con `partner: sistema54`, che firma
con i certificati Clanto e pubblica qui la release
(`sistema54-<versione>-x86_64.exe`, `.msi`, `.dmg`).

Le icone riproducono in vettoriale il simbolo del logo di sistema54.com
(sfumature verde `#d8d117` → `#9fa526` e blu `#0a9cd8` → `#2178be`). Regole dei
campi e delle icone: `res/partner-template/README.md` in `clanto/clantodesk-client`.
